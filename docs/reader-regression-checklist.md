# 阅读器回归清单

改动阅读页、排版内核、翻页或进度保存后，在真机上按本清单过一遍。命令行检查只覆盖纯逻辑，渲染和手势必须人工确认。

```powershell
node scripts/thread-blocking-check.mjs

node scripts/neutral-source-engine-check.mjs
node scripts/log-policy-check.mjs
node --experimental-strip-types scripts/java-regex-compat-check.mjs
node --experimental-strip-types scripts/replace-rule-import-check.mjs
node --experimental-strip-types scripts/opds-parser-check.mjs

node --experimental-strip-types scripts/reader-chunk-pagination-check.mjs
```

再构建一次调试 HAP，确认没有 ArkTS 编译错误。

## 测试素材

准备以下几本书，覆盖三条渲染路径和主要内容形态：

| 素材 | 用途 |
| --- | --- |
| 长篇 TXT（单章 1 万字以上） | 深位置恢复、增量分页 |
| 带插图的 EPUB | 图文混排分页 |
| 网络书（书源带段评） | 正文动作标记、段评面板 |
| 漫画 | 连续滚动、图片加载 |
| 对话密集且启用正则字体气泡的章节 | 装饰绘制、翻页快照 |

## 打开与恢复

- [ ] 从书架打开，首屏正文出现前没有白屏或背景闪烁
- [ ] 读到章节中后段退出，重新打开落在同一段文字
- [ ] 读到章节最后一页退出，重新打开仍是最后一页
- [ ] 打开后立即返回，书架进度没有被改成第 1 页
- [ ] 冷启动后从桌面卡片或快捷方式进入，位置正确
- [ ] 加载遮罩不会停留超过几秒；断网打开未缓存章节有明确的错误和重试入口

## 翻页

对每种翻页方式（无动画、平移、淡入、叠页、仿真、3D 仿真）各做一遍：

- [ ] 点击翻页、滑动翻页、音量键翻页都只翻一页
- [ ] 快速连点 10 次，页码前进 10 页，没有回弹或空白页
- [ ] 滑动到一半松手回弹，页面回到原位且文字不抖动
- [ ] 跨章节向后翻：章末 → 下一章第一页，无加载占位残留
- [ ] 跨章节向前翻：章首 → 上一章最后一页
- [ ] 翻页动画进行中按 Home，回到应用后正文与页码一致
- [ ] 横屏双页：左右两页内容连续，章末奇数页时右页为空而不是重复

## 滚动阅读

- [ ] 上下滚动流畅，快速甩动不出现空白块
- [ ] 滚到章末继续拉动进入下一章，章首继续下拉回上一章
- [ ] 退出再进，滚动位置恢复到同一段

## 排版

- [ ] 调整字号、行距、段距、四边距、字间距，当前阅读位置保持在同一段
- [ ] 切换对齐方式（两端、左、右），断行正常
- [ ] 切换字体（系统、内置、自定义导入），正文和标题都生效
- [ ] "保留段首缩进"开关前后，页首段落表现符合设置
- [ ] 页眉页脚开关、内容切换后，正文末行不被页脚遮挡
- [ ] 正文扩展至状态栏开关后，首行不被刘海或状态栏遮挡
- [ ] 旋转屏幕、分屏、折叠屏展开后重新分页，位置保持

## 主题

- [ ] 日间/夜间切换，正文颜色和背景立即同步，没有残留旧色
- [ ] 带背景图的主题，翻页时背景无接缝
- [ ] 跟随系统深色模式切换

## 选区与正文动作

- [ ] 分页模式长按选词，手柄和高亮与文字对齐；拖动手柄可扩展选区
- [ ] 滚动模式长按选词同上
- [ ] 复制的文本不含段评标记、图片标记和多余缩进
- [ ] 点击段评气泡打开段评面板；面板可拖动高度；关闭后可继续翻页
- [ ] 选中文字后带入"替换净化"新建规则

## 朗读

- [ ] 开始朗读，高亮跟随当前句；跨页时自动翻页
- [ ] 朗读中手动翻页，朗读从新页继续
- [ ] 朗读跨章节自动衔接
- [ ] 朗读中退到后台和锁屏，继续播放；回到前台高亮位置正确
- [ ] 朗读中返回书架，浮动控制条可用；再进入阅读页高亮同步
- [ ] 定时停止、语速调整生效

## 目录与书签

- [ ] 目录定位到当前章节；正序/倒序切换保持定位；搜索章节名
- [ ] 目录跳转后落在目标章节第一页
- [ ] 下拉添加书签；书签列表跳转位置正确；删除和多选删除

## 生命周期

- [ ] 阅读中切到其他应用再返回，正文、页码、主题一致
- [ ] 锁屏再解锁同上
- [ ] 从阅读页进入替换净化、字体设置再返回，只重排一次，位置不变
- [ ] 换源后正文更新，进度落在对应章节

## 设置面板与悬浮控件

- [ ] 排版调节（字号、字距、行距、段距、四边距）连续点按只重排一次，数值输入生效
- [ ] 页眉页脚各开关和内容选项生效并保存
- [ ] 自定义配色：新增、删除、改名、切换方案；背景色与背景图片切换；图片铺放方式；文字颜色；深浅色各自独立
- [ ] 朗读悬浮胶囊：显示状态、暂停/继续、关闭、拖动后位置保持；后台朗读时的胶囊同样可用
- [ ] 菜单上方的朗读控制条：定时、上一章、播放/暂停、下一章、语速、收起
- [ ] 眼动翻页：开启时请求相机权限；三步校准可完成、可取消；校准后向上看翻页；菜单或面板打开时不翻页

## 局域网阅读

- [ ] 无密码：浏览器直接打开书架、阅读、同步进度；封面与漫画图片正常显示
- [ ] 有密码：登录成功后可用；连续输错 5 次后提示稍后再试，等待后可再次登录
- [ ] 修改密码后旧浏览器会话失效
